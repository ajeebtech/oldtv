OLDTV

The old web, rebuilt page by page from Wayback Machine captures, for filming. Every page runs from this folder with no internet. Click any text to rewrite it, drag your own photos and videos onto anything, then press Esc for a clean shot.

How to use it on set
  • Open shows the bare page. In browser wraps it in a period browser window (IE6, Firefox 2, Safari 3, Chrome) with a fake address bar you can retype.
  • Edit text by clicking it. Hover a post, comment, friend or video to move, duplicate or delete it.
  • Drag an image or video from Finder onto any avatar, photo, thumbnail or player. On pages with custom backgrounds (MySpace, Twitter), drop onto empty space to set the background.
  • Esc toggles film mode: toolbar and outlines disappear, links click through between pages of the same site.
  • Edits and media are stored in this browser on this machine. Use Export on a page to carry it to another computer, Reset to start over.
  • For a full-screen take, use the browser's full-screen mode (⌃⌘F in Chrome/Safari) on an In browser page.
